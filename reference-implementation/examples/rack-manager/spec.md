# RACK-210: Ports and cabling tabs for racks and cabinets

Operators can see which ports are in use on a rack or cabinet and manage the cables between them without leaving the rack page.

## Acceptance criteria
- Ports tab label: Interfaces
- Port columns: Device, Port, Speed, Status
- Cabling tab label: Links
- Cable type options: Copper, Fibre
- Edit connection action: Edit connection
- Connection changes are written to the audit log
